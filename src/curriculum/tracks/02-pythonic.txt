=== pyx-01 | Closures: functions that remember | 2
::: story
A function defined inside another function can REMEMBER the outer variables,
even after the outer function returned. That's a closure.
```
def make_adder(n):
    def add(x):
        return x + n      # n is remembered
    return add
add5 = make_adder(5)
add5(1)   # 6
```
To REASSIGN an outer variable inside the inner function, declare it `nonlocal`.
::: task
1. `make_counter()` returns a function; each call returns the next integer
   starting from 1. Separate counters are independent.
2. `make_rate_limiter(max_calls)` returns a function `allow()` that returns
   `True` for the first `max_calls` calls and `False` afterwards.
::: starter
def make_counter():
    count = 0
    def next_value():
        pass
    return next_value

def make_rate_limiter(max_calls):
    pass
::: solution
def make_counter():
    count = 0
    def next_value():
        nonlocal count
        count += 1
        return count
    return next_value

def make_rate_limiter(max_calls):
    used = 0
    def allow():
        nonlocal used
        if used >= max_calls:
            return False
        used += 1
        return True
    return allow
::: hint
Without `nonlocal count`, `count += 1` raises UnboundLocalError.
::: hint
The rate limiter is the same shape: an outer `used = 0`, an inner `allow()` that checks then increments.
::: test counter counts
c = make_counter()
assert [c(), c(), c()] == [1, 2, 3]
::: test counters are independent
a, b = make_counter(), make_counter()
a(); a()
assert b() == 1
::: test rate limiter
allow = make_rate_limiter(2)
assert [allow(), allow(), allow(), allow()] == [True, True, False, False]
::: test zero limit
assert make_rate_limiter(0)() is False

=== pyx-02 | Decorators: wrapping functions | 3
::: story
A decorator is a function that takes a function and returns a new one that
adds behaviour around it. `@deco` above a def is shorthand for `f = deco(f)`.
```
import functools
def shout(fn):
    @functools.wraps(fn)          # keep fn.__name__ / docstring
    def wrapper(*args, **kwargs):
        return fn(*args, **kwargs).upper()
    return wrapper
```
Frameworks use decorators everywhere: `@tool`, `@traceable`, `@app.get`.
::: task
Write a decorator `count_calls` that:
- counts how many times the decorated function is called, exposed as an
  attribute `wrapper.calls` (starting at 0),
- passes through any args/kwargs and returns the original result,
- preserves `__name__` and `__doc__` using `functools.wraps`.
::: starter
import functools

def count_calls(fn):
    pass
::: solution
import functools

def count_calls(fn):
    @functools.wraps(fn)
    def wrapper(*args, **kwargs):
        wrapper.calls += 1
        return fn(*args, **kwargs)
    wrapper.calls = 0
    return wrapper
::: hint
Functions are objects — you can set attributes on them: `wrapper.calls = 0`.
::: hint
Inside wrapper: `wrapper.calls += 1` then `return fn(*args, **kwargs)`.
::: test counts calls
@count_calls
def add(a, b=0):
    "adds"
    return a + b
assert add.calls == 0
assert add(1, b=2) == 3
add(5)
assert add.calls == 2
::: test preserves metadata

    "Search the web."
    return q

::: test separate counters

=== pyx-03 | Decorators with arguments: @retry | 3
::: story
LLM APIs fail randomly (rate limits, timeouts). A `@retry` decorator re-runs
the call. To give a decorator arguments, add one more layer:
```
def repeat(n):           # 1. takes the arguments
    def deco(fn):        # 2. takes the function
        def wrapper(*a, **kw):   # 3. runs instead of fn
            ...
        return wrapper
    return deco
```
::: task
Write `retry(times, exceptions=(Exception,))`:
- calls the function up to `times` attempts in total,
- only retries on exceptions that are instances of `exceptions`; other
  exceptions propagate immediately,
- if every attempt fails, re-raise the LAST exception,
- record the number of attempts used by the most recent call in
  `wrapper.attempts`.
::: starter
import functools

def retry(times, exceptions=(Exception,)):
    pass
::: solution
import functools

def retry(times, exceptions=(Exception,)):
    def deco(fn):
        @functools.wraps(fn)
        def wrapper(*args, **kwargs):
            last = None
            for attempt in range(1, times + 1):
                wrapper.attempts = attempt
                try:
                    return fn(*args, **kwargs)
                except exceptions as exc:
                    last = exc
            raise last
        wrapper.attempts = 0
        return wrapper
    return deco
::: hint
`except exceptions as exc:` works with a tuple of exception classes.
::: hint
Loop `for attempt in range(1, times + 1)`, `return` on success, store the error otherwise, and `raise last` after the loop.
::: test succeeds after failures
state = {"n": 0}
@retry(3)
def flaky():
    state["n"] += 1
    if state["n"] < 3:
        raise ConnectionError("rate limited")
    return "ok"
assert flaky() == "ok" and flaky.attempts == 3
::: test raises last error
@retry(2)
def always():
    raise TimeoutError("slow")
try:
    always()
    assert False, "should raise"
except TimeoutError as e:
    assert str(e) == "slow"
assert always.attempts == 2
::: test does not retry other exceptions
calls = []
@retry(5, exceptions=(ConnectionError,))
def bad():
    calls.append(1)
    raise KeyError("x")
try:
    bad()
except KeyError:
    pass
assert len(calls) == 1, "KeyError must not be retried"
::: test passes arguments
@retry(1)

    return a * b
assert mul(3, b=4) == 12

=== pyx-04 | Context managers: tracing spans | 3
::: story
`with` blocks guarantee cleanup code runs, even on errors. Any class with
`__enter__` and `__exit__` works:
```
class Span:
    def __enter__(self):
        return self           # value bound by "as"
    def __exit__(self, exc_type, exc, tb):
        return False          # False = don't swallow the exception
```
Observability tools (LangSmith, OpenTelemetry) wrap every LLM call in a span.
::: task
1. Class `Span(name, log)` where `log` is a list:
   - on enter append `"start <name>"`, return the span itself
   - on normal exit append `"end <name>"`
   - on exception append `"error <name>: <message>"` and let it propagate
2. Function `use_setting(config, key, value)` built with
   `@contextlib.contextmanager`: temporarily sets `config[key] = value` and
   restores the old value afterwards (delete the key if it didn't exist) —
   even if the block raises.
::: starter
import contextlib

class Span:
    def __init__(self, name, log):
        self.name = name
        self.log = log

@contextlib.contextmanager
def use_setting(config, key, value):
    yield
::: solution
import contextlib

class Span:
    def __init__(self, name, log):
        self.name = name
        self.log = log

    def __enter__(self):
        self.log.append(f"start {self.name}")
        return self

    def __exit__(self, exc_type, exc, tb):
        if exc_type is None:
            self.log.append(f"end {self.name}")
        else:
            self.log.append(f"error {self.name}: {exc}")
        return False

_MISSING = object()

@contextlib.contextmanager
def use_setting(config, key, value):
    old = config.get(key, _MISSING)
    config[key] = value
    try:
        yield config
    finally:
        if old is _MISSING:
            del config[key]
        else:
            config[key] = old
::: hint
In `__exit__`, `exc_type is None` means the block finished normally.
::: hint
For the generator version, put `yield` inside `try:` and restore in `finally:`. Use a sentinel object to tell "missing" from "None".
::: test span success

    assert isinstance(s, Span)
    log.append("work")
assert log == ["start llm", "work", "end llm"]
::: test span error propagates
log = []
try:
    with Span("tool", log):
        raise ValueError("boom")
    assert False, "exception was swallowed"
except ValueError:
    pass
assert log == ["start tool", "error tool: boom"]
::: test nested spans
log = []
with Span("chain", log):
    with Span("llm", log):
        pass
assert log == ["start chain", "start llm", "end llm", "end chain"]
::: test setting restored

    assert cfg["temp"] == 0.0
assert cfg == {"temp": 0.7}
::: test new key removed and restore on error

    with use_setting(cfg, "debug", True):
        assert cfg["debug"] is True
        raise RuntimeError
except RuntimeError:
    pass
assert cfg == {}

    content: str

2. Define `class ChatMessage(TypedDict)` with `role: Role` and `content: str`.
3. Write `validate(msg) -> bool`: True only if msg is a dict with exactly the
   keys of ChatMessage, content is a str and role is one of Role's options.
   Read the keys and options FROM the type hints (don't hard-code them twice).
::: starter
from typing import Literal, TypedDict, get_args, get_type_hints

    pass
::: solution
from typing import Literal, TypedDict, get_args, get_type_hints

Role = Literal["system", "user", "assistant", "tool"]

class ChatMessage(TypedDict):
    role: Role
    content: str

def validate(msg) -> bool:
    hints = get_type_hints(ChatMessage)
    if not isinstance(msg, dict) or set(msg) != set(hints):
        return False
    return isinstance(msg["content"], str) and msg["role"] in get_args(Role)

::: hint
`msg["role"] in get_args(Role)` checks the Literal's options.

=== pyx-07 | Enums for routing | 2

2. `route_for(text)` -> `Route.MATH` if the text contains a digit,
   else `Route.CODE` if it contains "python" or "bug" (case-insensitive),
   else `Route.CHAT`.
3. `parse_route(value)` -> the Route for a string like `"code"` (any case);
   unknown values return `Route.CHAT`.
::: starter

    pass

    pass

    pass
::: solution
from enum import Enum

class Route(Enum):
    MATH = "math"
    CODE = "code"
    CHAT = "chat"

def route_for(text):
    lower = text.lower()
    if any(ch.isdigit() for ch in text):
        return Route.MATH
    if "python" in lower or "bug" in lower:
        return Route.CODE
    return Route.CHAT

def parse_route(value):
    try:
        return Route(value.lower())
    except ValueError:
        return Route.CHAT
::: hint
`any(ch.isdigit() for ch in text)` checks for a digit.
::: hint
`Route("code")` looks a member up by value and raises ValueError if unknown.

=== pyx-08 | Iterators: paginating an API | 3
::: story
`for x in obj` calls `iter(obj)` then `next()` repeatedly until
`StopIteration`. Implement `__iter__` and `__next__` to make your own:
```
class Countdown:
    def __init__(self, n): self.n = n
    def __iter__(self): return self
    def __next__(self):
        if self.n == 0: raise StopIteration
        self.n -= 1
        return self.n + 1
```
::: task
Write `class Paginator(items, page_size)` that yields lists (pages) of at most
`page_size` items. Requirements:
- implement `__iter__` and `__next__` (no generators this time),
- `__len__` returns the number of pages,
- iterating a second time starts over from page 1 (hint: `__iter__` resets).
- `page_size` < 1 raises `ValueError` in `__init__`.
::: starter
class Paginator:
    def __init__(self, items, page_size):
        pass
::: solution
class Paginator:
    def __init__(self, items, page_size):
        if page_size < 1:
            raise ValueError("page_size must be >= 1")
        self.items = list(items)
        self.page_size = page_size
        self.pos = 0

    def __iter__(self):
        self.pos = 0
        return self

    def __next__(self):
        if self.pos >= len(self.items):
            raise StopIteration
        page = self.items[self.pos:self.pos + self.page_size]
        self.pos += self.page_size
        return page

    def __len__(self):
        return (len(self.items) + self.page_size - 1) // self.page_size
::: hint
Keep a `self.pos` index. In `__next__`, slice a page then advance pos.
::: hint
Number of pages is ceiling division: `(n + size - 1) // size`.

from collections import Counter, defaultdict, deque

def top_words(texts, n):
    counts = Counter(w for t in texts for w in t.lower().split())
    return counts.most_common(n)

def group_by_source(chunks):
    groups = defaultdict(list)
    for c in chunks:
        groups[c["source"]].append(c["text"])
    return dict(groups)

class WindowMemory:
    def __init__(self, size):
        self._buf = deque(maxlen=size)

    def add(self, msg):
        self._buf.append(msg)

    def messages(self):
        return list(self._buf)
::: hint
`Counter(generator)` counts anything iterable; `.most_common(n)` gives the top n.
::: hint
`deque(maxlen=size)` automatically drops from the left when full.

::: test window memory

=== pyx-11 | Regex: parsing ReAct output | 4
::: story

```

```

2. `parse_final(text)` -> the text after `Final Answer:` (stripped, may span
   multiple lines), or `None`.
3. `extract_code(text)` -> list of the contents of all fenced code blocks
   (three backticks, optional language name after them), each stripped.
::: starter
import re

    pass

    pass

    pass
::: solution
import re

def parse_action(text):
    matches = re.findall(r"Action:\s*(\w+)\[(.*?)\]", text)
    if not matches:
        return None
    tool, arg = matches[-1]
    return tool, arg.strip()

def parse_final(text):
    m = re.search(r"Final Answer:\s*(.*)", text, re.S)
    return m.group(1).strip() if m else None

def extract_code(text):
    return [b.strip() for b in re.findall(r"`{3}[\w+-]*\n(.*?)`{3}", text, re.S)]
::: hint
`re.findall` with two groups returns a list of tuples; take `[-1]` for the last.
::: hint
For code blocks, match three backticks with a backtick followed by the quantifier {3}, then an optional language word, a newline, and a lazy (.*?) group — with re.S so it spans lines.
::: test parse action

::: test last action wins
